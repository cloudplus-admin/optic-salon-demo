# Optica — demo skeleton

Desktop-first HTML-демо единой системы управления салоном или сетью салонов оптики.

Онлайн-демо: <https://cloudplus-admin.github.io/optic-salon-demo/>

## Запуск

Откройте `index.html` в браузере либо запустите локальный сервер:

```bash
python3 -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Что уже есть

- адаптивный dashboard продавца;
- сворачиваемая боковая навигация по всем основным модулям;
- KPI-карточки, фильтрующие журнал заказов;
- поиск и статусы заказов с цветом, текстом и пиктограммами;
- уведомления и быстрые действия;
- первый шаг модального сценария создания заказа;
- HTML-каркасы заказов, клиентов, кассы, склада, накладных, отчетов, аналитики, справочников и настроек.

## Интерактивное демо

- создание, просмотр, изменение, копирование и удаление клиентов, товаров, накладных и значений справочников;
- профиль сотрудника с редактированием контактов, роли, салона и загрузкой аватара;
- сохранение демо-данных и фотографии в `localStorage`;
- пошаговое создание заказа: клиент, рецепт и товары, расчет, подтверждение;
- открытие и закрытие кассовой смены;
- поиск, фильтрация и CSV-экспорт данных;
- формирование ценников, настройки и демонстрационные отчеты/графики.
- отдельная доска мастерской с этапами изготовления;
- сотрудники и ролевая принадлежность по салонам;
- реальные селекторы салона и периода, расширенные фильтры заказов;
- прием оплаты/возврата и журнал последних кассовых операций;
- импорт Excel/CSV для номенклатуры и накладных.

Это первая статическая версия. Следующий этап — перенос в React + TypeScript, полноценные формы и состояние, затем API и модель данных.
